# 학습 진행사항 — 따릉이 재배치 RL

> 작성일: 2026-06-03 (최신: BC v7 오전 피크 가중 — 휴리스틱 첫 추월)
> 출처: `docs/experiments_2026-05-30.md` (ablation), `docs/experiments_2026-06-03.md` (피크 가중 돌파)

## 1. 문제 설정

- **환경**: 마포구 146개 정류소, 재배치 트럭 3대, 1 episode = 1일 = 144 step (10분 단위)
- **Train**: 2025년 292일 (random shuffle)
- **Eval (고정 7일, 미학습)**: `2025-03-25, 04-18, 05-17, 07-01, 07-06, 07-09, 08-21`
- **비교 기준 (휴리스틱)**: `MostImbalancedPolicy` greedy — 잉여 큰 곳 → 부족 큰 곳
- **평가 방식**: deterministic 7일 순회 (seed=42). RL/휴리스틱 모두 동일 환경·동일 reward 함수로 측정 → **격차로 우열 판단**

> 휴리스틱 baseline: **-500.0** (deterministic 7일 평균)

## 3. 진행 흐름 (3단계)

### 1단계 — 노브 튜닝 plateau (실험 2.1~2.14)

DQN → MaskableDQN → reward shaping → DDQN → lr_decay 등 **14번 ablation**.
-657 → -593에서 정체 (격차 -93).

- 가장 강력했던 개입: `action_masks()`의 **자기 위치 stay 기본 차단 (한 줄)** — trivial "한 곳에 모여 영원히 stay" 솔루션 제거
- big net `[512,512,256]`은 over-fit으로 오히려 -40점 악화
- lr_decay: +9.7점, best step을 학습 후반(110k→880k)으로 이동

### 2단계 — 평가 방식 교정 (실험 2.11)

`MaskedEvalCallback`의 **random reset 평가가 misleading** (학습 best -457 ↔ deterministic 측정 -655, 200점 괴리).
→ **deterministic 7일 순회 평가**로 통일하여 진짜 best 모델 선택 가능.

### 3단계 — Imitation Learning prior (실험 2.15~2.22) 🎯 plateau 돌파

휴리스틱을 Behavior Cloning으로 모방 → 그 가중치로 RL fine-tune.

```
[1단계 BC] 휴리스틱 시뮬레이션 → (obs, action) 쌍 → q_net을 cross-entropy 학습
[2단계 RL] BC 가중치를 시작점으로 RL fine-tune (100k면 충분)
```

| 실험 | 변경 | det. 평균 | 격차 |
|---|---|---:|---:|
| 2.17 BC v2 + RL | 60일 데이터, BC acc 22% | -539.6 | -39.6 (1일 추월) |
| 2.21 BC v5 + RL | 미래 demand obs 추가, BC acc 50% | -557.6 | -57.6 ❌ 악화 |
| **2.22 BC v6 + RL** | **데이터 292일**, BC acc 20% | **-506.6** | **-6.6** (3일 추월) |

가장 효과 큰 단일 변경: **BC 학습 데이터 60일 → 292일** (-33점 도약).

## 5. 결정적 인사이트

- ✅ **데이터 다양성이 본질** — 60일 → 292일이 -33점 도약
- ❌ **BC accuracy는 misleading 지표** — v5(50%)가 v2(22%)보다 RL 결과 나쁘고, v6(20%)이 가장 좋음. acc는 memorize 정도일 뿐 RL 일반화와 별개
- ❌ **미래 demand obs (v5)는 역효과** — feature 추가가 항상 도움 안 됨
- ❌ **catastrophic forgetting** — fine-tune 100k면 충분, 그 이상은 손해 (best가 step 5k~10k에 나옴)
- ⚠️ **stay 차단은 `rebalance_env.py:action_masks()`에 hard-coded** — 2.8 이후 모든 학습에 영구 적용 (끄려면 코드 수정 필요)

## 6. 남은 도전 (격차 -6.6)

어려운 날에서 여전히 RL이 약함: **05-17 (-61.3)**, 07-06 (-13.1).

다음 시도 후보:
1. **KL penalty / EWC** — RL이 BC prior를 더 보존하도록
2. **더 짧은 fine-tune** (5k → 3k, 1k) — forgetting 회피
3. **어려운 날 domain-specific tuning** (05-17 등 추가 학습)
4. **PPO / A2C** — DQN의 후반 발산 회피
5. BC를 더 큰 net으로 (단 over-fit 주의)
