# RTDP 소규모 실험 — 현재 환경 & 진행 과정 (2026-06-06, 갈래 A)

> 목적: 서영현(2022) 논문처럼 **RTDP(테이블형 확률적 동적계획)로 휴리스틱을 *실제로* 추월**하는 것을 마포구 데이터로 재현. model-free RL(DQN/PPO)이 아니라 model-based DP. 코드: [scripts/rtdp_small.py](../scripts/rtdp_small.py).

이전 셋업(근거리 6정류소·고정 50% 목표)에서는 RTDP ≈ STR(추월 실패). **갈래 A**는 RTDP가 빛날 3조건을 갖춰 다시 시도하는 중.

---

## 1. 환경 (축소된 MDP)

| 항목 | 값 | 비고 |
|---|---|---|
| 지역 | 마포구 | 전체 146정류소 중 일부만 사용 |
| 학습용 수요 | TRAIN_DATES 60일 평균 | Poisson 분포의 *평균(λ)*으로 사용 |
| 평가용 수요 | EVAL_DATES 7일 (held-out 실제) + Poisson 30회 | |
| **정류소** | **6개 + depot** | ① top-25 번잡 중 **greedy farthest-point**로 *지리적으로 퍼지게* 선택 → 이동 2~4 step |
| **트럭** | **1대**, 적재용량 30 | |
| **시간창** | **07:00–10:00** (step 42–60, **18 step**) | 출근 피크, 10분/step |
| 수요 모델 | **확률적 Poisson(λ=forecast 평균)** | 논문과 동일(결정론 아님) |
| depot | 무한 버퍼 | 방문 시 트럭 적재 비움(dump) |

### 상태 (State)
```
s = (k,  트럭위치,  정류소별 3-레벨 밴드 인덱스)
        k=시각      위치∈{0..5, depot}   각 정류소: 0=밴드아래(빔) / 1=밴드안 / 2=밴드위(참)
```
- 밴드 = 목표(capacity×50%) ± 안전버퍼(capacity×20%).
- **동역학은 exact 정수재고**로 시뮬, **가치테이블 V만 밴드 인덱스로 축약**(논문 fill-rate index) → 상태폭발(2^|N|) 완화·수렴.

### 행동 (Action) — ② 적재량 lever 추가
```
a = (목표레벨,  다음목적지)
     레벨∈{0:거의비움(0.1c), 1:중간(0.5c), 2:거의채움(0.9c)}    목적지∈{정류소들, depot}
```
- 현재 위치 정류소를 *목표레벨*까지 재배치(트럭 적재/용량 제약) 후 목적지로 이동.
- **RTDP는 레벨을 자유 선택** → 곧 반납이 몰릴 정류소는 미리 비우고(0.1c), 곧 대여가 몰릴 곳은 미리 채움(0.9c) = **예측 over/under-fill**.

### 비용 (Reward)
- 매 step **미충족수요 = 대여실패(stockout) + 반납실패(full)**. **낮을수록 좋음.**

## 2. 진행 과정 (Process)

### (A) RTDP 학습 — Barto(1995) Algorithm 1
비동기 가치반복 + 궤적 샘플링:
```
V0(s) = 0  (비용≥0 이라 admissible 하한)
반복 I회:
  s ← 시작상태(k=42, depot, 적재0, 초기재고)
  while k < 60:
     각 행동 a=(레벨,목적지)에 대해
        q(a) = (1/M) Σ_m [ cost_m(s,a) + γ^τ · V(s'_m) ]     # M-샘플 Monte-Carlo 기대
     V(s) ← min_a q(a)                                          # 비동기 백업(방문 상태만)
     a* = argmin;  s ← a* 1회 샘플 실현으로 진행
```
- γ=0.95, M=4~5(백업 샘플 수), τ=이동 step.
- 미방문 상태 V=0(낙관적 하한) → 반복하며 채워짐. 방문 상태만 dict로 저장.

### (B) 비교 휴리스틱
| 정책 | 라우팅 | 재배치량 |
|---|---|---|
| do-nothing | 안 움직임 | 없음 |
| **STR (반응형)** | 밴드 밖 *가장 가까운* 정류소 | ③ **최소**(밴드 가장자리까지만) — 논문식 myopic |
| **SLA (정적 lookahead)** | 미래 net 예측 불균형 최대 정류소 | 중간(50%) |
| **RTDP** | 가치함수 1-step lookahead | 자유(레벨 선택) |

### (C) 평가
- **확률 Poisson 30회**: λ=forecast로 30개 시나리오 샘플 → 평균 미충족수요(±표준편차) + 평균 배달량.
- **held-out 실제 7일**: 평가일의 *실제* 대여/반납으로 롤아웃 → 평균 미충족수요.
- 판정: **RTDP < STR(그리고 SLA)** 이면 추월 ✅.

## 3. 결과 — ❌ RTDP 추월 실패 (확정)

진행 중 **샘플 백업의 optimizer's curse**(노이즈 q 중 운 좋은 극단 행동을 min이 선택 → 과배달 편향) 발견 → **분석적 기댓값 백업**으로 교정(Poisson 미충족수요 precompute, 변동성 0, 런타임 6분→2분).

최종 (iters=12000, 분석적 백업, 미충족수요↓):
| 정책 | 확률 Poisson(30) | 배달량 | 실제(7일) |
|---|---|---|---|
| do-nothing | 19.10 | 0 | 31.71 |
| STR (반응·최소재배치) | 8.33 | 24.2 | 17.14 |
| **SLA (예측형 lookahead)** | **5.63** ⭐ | 33.5 | **11.71** ⭐ |
| RTDP (확률적 DP) | 8.43 | 57.4 | 16.71 |

- **RTDP ≈ STR(반응형) 수준**(확률 8.43 vs 8.33), **예측형 SLA(5.63)엔 크게 못 미침**. 실제일선 STR 미세 추월(16.71<17.14)이나 SLA(11.71)엔 한참 못 미침.
- RTDP **배달량 57.4로 과배달 지속** — 분석 백업으로도 못 고침.

### 왜 추월 실패했나
1. **상태(밴드 인덱스) 축약이 과배달을 못 벌함** — "밴드 안"이면 적정/극단 구분 못 함 → 가치함수가 낭비를 못 잡음(배달 57.4).
2. **certainty-equivalent(평균수요) 백업이 확률 스파이크 실패를 과소평가** → 과배달이 안전해 보임.
3. **예측형 SLA가 강한 baseline** — 논문 SLA는 25/50/75%만·1회 방문으로 *제약*돼 약했음(그래서 논문 RTDP≫SLA). 우리 SLA는 자유 예측형이라 강함 → RTDP가 넘을 여지 없음.

### 결론
- **논문의 "RTDP가 휴리스틱 추월"은 ① 작은 문제(coarse state로 충분) + ② 제약된 baseline(약한 STR/SLA)의 산물.** 마포구에 충실히 재현하고 **강한 예측형 baseline**을 두면, RTDP는 반응형 수준에 머물고 예측형을 못 넘는다.
- 이는 프로젝트 중심 발견을 재확인: **예측형 휴리스틱이 진짜 레버이고, model-free RL도 model-based RTDP도 강한 예측형을 능가하지 못한다.**
- (참고) RTDP를 더 끌어올리려면 finer state(실재고/적재 포함)가 필요하나 테이블 폭발 → 소규모에서만 가능, 그래도 강한 예측형 추월은 미지수.
