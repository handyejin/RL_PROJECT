📚 따릉이 RL 프로젝트 — 소스 가이드

프로젝트 개요

서울시 공공자전거 따릉이의 정류소 간 재배치 문제를 강화학습으로 푸는 프로젝트.
트럭 N대가 자전거를 옮겨 대여실패(stockout) + 반납실패(full)을 최소화. SB3 DQN 기반.

📂 전체 구조 (한눈에)

rl_project/
├── src/data/preprocess.py          ← 원본 CSV → parquet 4종 변환
├── src/utils/geo.py                ← Haversine 거리 / 이동 step 계산
├── src/envs/data_loader.py         ← episode 1개분 numpy 묶음 생성
├── src/envs/rebalance_env.py       ← Gymnasium 환경 (시뮬레이터)
├── src/agents/baselines.py         ← NO-OP, most_imbalanced 휴리스틱
├── src/agents/masked_dqn.py        ← SB3 DQN + action mask + Double Q
├── scripts/run_preprocess.py       ← 전처리 진입점
├── scripts/test_env.py             ← 환경 sanity check
├── scripts/run_baseline.py         ← 베이스라인 비교 (Phase 3)
├── scripts/train.py                ← DQN 학습 (Phase 4)
├── scripts/export_replay.py        ← 학습 모델 → replay JSON
├── scripts/plot_demand.py          ← EDA 시각화
└── config/default.yaml             ← 하이퍼파라미터 (참조용)

🔗 관련 인터랙티브 문서

→ training_flow.html — 환경 + DQN 흐름 시뮬레이터 (5 정류소 미니 버전) → replay_viewer.html — 학습된 모델 episode 재생 (실제 마포구 146 정류소) → training_curve.png — DQN 학습 곡선 이미지

👉 사용법

  • 좌측 트리에서 파일 클릭 → 상세 정보 (역할, 함수 목록, 의존성, 코드 스니펫)
  • 상단 탭 데이터 흐름 → CSV → parquet → 학습까지의 노드 다이어그램. 노드 클릭 시 해당 파일로 이동
  • 상단 탭 호출 관계 → 어떤 스크립트가 어떤 모듈을 부르는지 매트릭스
  • 상단 검색창 → 파일·함수 이름 일부 입력 시 트리에서 필터링
📂

좌측에서 파일을 선택하세요

파일별 역할, 핵심 함수, 의존성, 코드 스니펫을 볼 수 있습니다.

데이터 흐름 다이어그램

원본 CSV가 어떻게 학습 가능한 형태로 변환되고, 환경·DQN에 공급되어 모델이 학습/평가되는지 시각화. 노드를 클릭하면 해당 파일 상세로 이동.

호출 관계
