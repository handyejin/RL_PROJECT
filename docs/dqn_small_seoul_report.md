# 소규모 DQN(자전거 재배치) — 서울 25개 자치구 평가 보고서

> 작성일 2026-06-08 · 환경 축소(출퇴근 압력 top-15 정류소·트럭 1대)로 RL이 예측형 데이터를
> 받아 반응형 휴리스틱을 넘을 수 있는지, 서울 전역 25개 구에서 검증한다.

---

## 1. 요약 (Executive Summary)

- **소규모(N=15) DQN은 일부 구에서 반응형 휴리스틱(most_imbalanced)을 유의하게 추월**한다
  (강남 +8.3, 송파 +11.1, 성북 +3.3 — 95% CI가 0을 넘지 않음). 전역으로는 **25구 중 6구 추월,
  구 평균 Δ −5.3**으로 혼재된 결과다.
- **학습량(200k→400k)은 휴리스틱과의 격차를 줄이지만**, "추월(Δ>0) 전환"은 제한적이다(양적 개선 위주).
- **Poisson 확률 수요·VAE latent 보강은 추월폭을 키우지 못했다.** 본 환경에서 추월의 핵심은
  forecast/표현 보강이 아니라 **라우팅 정책 학습 자체**다.

---

## 2. 환경 (Environment)

전체 자치구(정류소 수십~수백) + 다트럭에서는 model-free DQN이 학습 자체에 실패했다.
"배울 수 있는 크기"로 축소해 학습 가능성을 확보한다.

| 항목 | 설정 |
|---|---|
| 대상 | 서울 25개 자치구 각각 (독립 학습·평가) |
| 정류소 | **출퇴근 불균형 압력 top-15** (아침 07–10·저녁 17–21 피크의 \|반납−대여\| 합 상위) |
| 트럭 | 1대 (용량 20) |
| 시간축 | 하루(144 step, 10분/step) |
| 수요 | 결정적 replay(기록값) 기본, Poisson 확률 수요는 별도 실험 |
| 데이터 | `data/processed_seoul_all` (전 구 수요·거치대·날씨) + 구별 forecast parquet |

**비용(=리워드, 높을수록 좋음):** `stockout×(−1.0) + full×(−0.8) + 이동km×(−0.008) + 이동step×(−0.002)`

### 상태(State) 구성 (obs_dim 92)
| 구성 | 차원 |
|---|---|
| 정류소 재고율 | 15 |
| 트럭(위치·적재·남은이동·현재트럭) | 4 |
| 시각 sin/cos·진행 | 4 |
| **캘린더(요일 sin/cos·주말·공휴일·휴일전날)** | 5 |
| **날씨(기온·강수·풍속·습도)** | 4 |
| **forecast 미래 순수요(15×4)** | 60 |
- 행동: 목적지 정류소 선택(15). 알고리즘: MaskableDQN(Double), net [256,256].
- (옵션) VAE 수요 latent 추가 시 obs_dim 152.

## 3. 평가 방법 (Evaluation)

- **분할:** 2025년 365일을 seed-42로 셔플 → **train 292일(80%) / holdout 73일(20%)**.
  학습은 train 풀에서 200일 사용(`--n-train-dates 200`).
- **평가 표본:** holdout **73일 전체** (초기 7일 평가의 표본 부족·best-on-test 편향을 제거).
- **모델:** 학습 종료 시점(**final**) 정책 (평가셋에서 best를 고르지 않음 → 낙관 편향 제거).
- **프로토콜:** greedy 롤아웃, 베이스라인(most_imbalanced)과 **동일 수요 실현을 공유하는 paired** 비교.
- **지표:** 일별 보상차 Δ=모델−휴리스틱의 **평균 ± 95% CI**, 추월일수(Δ>0인 날 / 73).
- **2단계 보고:** (구내) 73일 Δ±CI / (전역) 추월 구수 N/25·구별 Δ 분포.
- **한계:** 각 구는 **독립 모델·단일 학습 seed**. "추월 N/25"는 구 특성+seed 노이즈가 섞인
  서술적(breadth) 결과이며, 한 모델의 공간적 전이(cross-district)를 의미하지 않는다.
  random 분할이라 계절성 누수 가능성도 한계로 둔다.

## 5. 보조 실험 (Ablation)

### 5-1. 학습량 효과 (200k → 400k, 7일 best 기준, 25구)
| | 추월 | 구 평균 Δ |
|---|---|---|
| 200k | 7/25 | −6.2 |
| 400k | 8/25 | −2.1 |
- 15/25 구에서 Δ 개선(강서 +27.5·광진 +20.0 등 대폭). **격차는 뚜렷이 줄지만** 추월 전환은
  성동 1구뿐 → **학습량은 양적 개선 위주, 질적(추월) 전환은 제한적.**
- (주: 본 절은 7일·best 기준 비교. §4의 73일·final 대표 수치와 표본/모델 기준이 다름.)

### 5-2. forecast 기여 (강남, poisson 400k, A vs C)
| 조건 | Δ |
|---|---:|
| forecast ON | +10.4 |
| forecast OFF | +7.9 |
→ **forecast 기여 ≈ +2.5 (양이지만 작음).** 추월의 대부분은 forecast가 아니라 라우팅 학습에서 나옴.

### 5-3. Poisson 확률 수요 (3구, holdout 73일)
| 구 | 결정적 Δ | Poisson Δ |
|---|---:|---:|
| 강남 | +8.3 ± 3.2 | +6.9 ± 2.8 |
| 마포 | −2.4 ± 4.0 | −10.1 ± 1.9 |
| 도봉 | −1.5 ± 2.0 | −5.2 ± 1.2 |
→ **Poisson이 일관되게 같거나 나쁨.** "확률화가 forecast 이점을 살린다"는 본 환경에선 성립 안 함
(그 현상은 단순화된 SmallProblem 환경 특유였음, [docs/dqn_small_overtake_recipe.md](dqn_small_overtake_recipe.md)).

### 5-4. forecast + VAE latent (3구, 400k, 7일 best)
| 구 | forecast-only Δ | forecast+VAE Δ |
|---|---:|---:|
| 강남 | +11.2 | +9.6 |
| 마포 | +7.7 | +4.9 |
| 도봉 | −0.8 | −2.2 |
→ **VAE는 도움 안 됨(3구 모두 소폭 악화).** obs 차원만 92→152로 키워 학습을 어렵게 함.

## 6. 결론

1. **"문제를 배울 수 있는 크기로 줄이면 RL이 예측형 데이터로 반응형 휴리스틱을 넘을 수 있다"**
   — 강남·송파·성북에서 통계적으로 확인. 단 **전역적으로 보장되지는 않음**(6/25).
2. **추월 여부는 구 특성(수요 규모·재배치 여지)에 의존**한다. 너무 작거나 초대형 고수요 구는
   단일 트럭·15정류소 축소로는 한계.
3. **추월의 동력은 라우팅 정책 학습**이며, forecast(+2.5)·Poisson(무효)·VAE(악화)·학습량(양적
   개선)은 부차적이다.

### 한계 & 향후
- **단일 seed** → 대표 구(강남·송파·성북) 다중 seed로 평균±CI 보강 필요.
- **cross-district 전이**(일부 구 학습→안 본 구 평가) 미검증 — 실제 배포 가치 큰 다음 실험.
- 다트럭·구역분할로 초대형 구(강서·영등포) 대응 검토.
